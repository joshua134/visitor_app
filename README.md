# Visitor Management System

A secure, and modern Visitor Management System built with Spring Boot, featuring email notifications, CAPTCHA protection, and advanced reporting capabilities.

## 🚀 Features

### Core Features
- **Visitor Registration** - Secure visitor registration with CAPTCHA protection
- **Email Notifications** - Automatic email confirmation on registration
- **Role-Based Access Control** - ADMIN, MANAGER, and VIEWER roles with different permissions
- **User Management** - Invite users, manage roles, enable/disable accounts
- **Forced Password Change** - First-time login password change requirement
- **Password Reset** - Secure password reset with email verification

### Admin Features
- **Dashboard** - Real-time statistics and visitor overview
- **Visitor Management** - Search, filter, and view all visitors
- **User Management** - Invite, manage roles, enable/disable users
- **Role Management** - Create, edit, and delete custom roles
- **Report Generation** - Export data to PDF, Excel, and print
- **Audit Trail** - Track all visitor registrations

### Security Features
- **AES-256 Encryption** - All personal data encrypted
- **BCrypt Password Encoding** - Secure password storage
- **CSRF Protection** - Cross-site request forgery protection
- **Session Management** - Secure session handling
- **Remember Me** - Persistent login functionality
- **CAPTCHA** - Bot protection on registration forms
- **Rate Limiting** - Prevent brute force attacks

### Technical Features
- **Spring Boot 3.x** - Modern Java framework
- **Spring Security** - Comprehensive security framework
- **Thymeleaf** - Server-side HTML templating
- **MySQL** - Relational database
- **Flyway** - Database migration management
- **Tailwind CSS** - Modern, responsive UI
- **Alpine.js** - Lightweight JavaScript framework
- **PDF/Excel Export** - Reporting capabilities
